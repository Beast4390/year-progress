# 🚀 Year Progress Wallpaper

A minimalist, fully automated **Year Progress Wallpaper** for Android that updates every day to visualize the progress of the current year. The project uses a web-based wallpaper and Android automation to generate a fresh wallpaper daily—no manual updates required.

---

## ✨ Features

- 📅 Dot-based grid representing all 365 days of the year
- ⚪ Completed days
- 🟢 Highlights today's date
- ⚫ Upcoming days
- 🎯 Marks special dates
- 📊 Live year completion percentage
- ⏳ Days completed and remaining
- 💬 Motivational quotes that refresh over time
- 📱 Responsive design optimized for Android devices
- ⚡ Fully automated wallpaper updates using MacroDroid

---

## ⚙️ Automation Workflow

Using **MacroDroid**, the wallpaper updates automatically every day.

1. Trigger at **12:01 AM**
2. Open `wallpaper.html` (or the hosted webpage)
3. Wait for the page to load
4. Capture a full-screen screenshot
5. Set the screenshot as the home screen wallpaper

After setup, the wallpaper updates automatically every day.
